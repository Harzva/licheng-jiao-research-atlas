# 焦李成教授研究图景综述

本目录提供一份可复现的文献计量与主题演化综述，覆盖 Research Atlas
收录的 1998—2026 年学术记录。

- [`index.html`](./index.html)：英文语义化版本。
- [`zh/index.html`](./zh/index.html)：与英文版同结构的中文语义化版本。
- [`main.tex`](./main.tex)：遵循 arXiv HTML 转换建议组织的 LaTeX 源稿。
- [`references.bib`](./references.bib)：综述引用的论文与数据来源。
- [`figures/`](./figures/)：由公开数据生成的 5 张原创综述图（SVG 与 PNG）。
- [`qr/`](./qr/)：扫码直达每张高清 SVG 原图的二维码。
- `main.pdf`：由仓库中的 LaTeX 源稿编译生成。

## 证据边界

当前综述以 DBLP 作者档案、DOI、题名、作者、来源、年份和 Crossref
Cited-by 计数为证据。主题与任务由可解释的题名规则归类，因此适合描述研究版图，
不替代逐篇全文精读。引文计数会随时间变化，而且 Crossref 只能统计已进入其
Cited-by 网络的引用；文中始终标明数据源与更新时间。

Scopus 2,564 documents 与百度学术约 3,983 项成果作为跨数据库扩展信号保留，
但没有与 DBLP 记录直接相加。当前语料包含 453 条会议记录和 126 个会议来源，
却没有原生中文会议元数据；中文会议与中文期刊将通过 CNKI、万方和机构档案
另行补采并执行作者身份与版本去重。

## 可访问性原则

稿件使用标准前置信息、语义化章节、原生表格与描述性链接。HTML 版本保留清晰的
标题层级、跳转导航、表格说明和可见焦点；LaTeX 版本避免用纯视觉排版命令表达
文档结构，并为每张图保留替代描述，以提高 LaTeXML 转换成功率。
