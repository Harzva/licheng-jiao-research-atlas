Cross-database coverage

发现规模不等于
唯一论文总数。

Scopus、百度学术和 Google Scholar 的统计单位与收录边界不同。 这里并列展示发现规模，但在完成作者身份消歧、文献类型统一和版本聚合前，不把它们与 DBLP 直接相加。

外部数字为本轮扩展规划所采用的人工快照：Scopus 2,564 documents；百度学术约 3,983 项成果； Google Scholar 因访问验证暂不提供可复现总数。下一轮将优先从 CNKI、万方及机构来源补采中文会议与中文期刊记录。

    01 / 身份基线

    以 DBLP 作者档案 40/3714 与 DOI 为身份锚点，降低同名作者与重复版本造成的误差。

    02 / 版本关系

    DOI、DBLP Key 与 arXiv ID 用于识别同一工作的不同版本；记录数量不等同于唯一研究工作数。

    03 / 摘要策略

    仅展示来源明确的摘要；缺失时直接链接论文页面，不以推测性文本替代原始内容。

    04 / 数据更新

    公开数据经过字段白名单与来源校验，更新日期显示在首页，便于读者判断数据时效。

    05 / 两级主题

    大领域与研究任务依据题名和来源中的可解释词汇归类，用于导航，不作为作者本人给出的研究分类。

    06 / 引用层

    引文来自 Crossref Cited-by；页面保留原始计数，并按发表年份识别相对高被引记录，不等同于 Google Scholar 总引用。

    07 / 数据库边界

    Scopus 与百度学术数字作为扩展线索保存，尚未导入主语料；跨库合并必须先完成作者、类型和版本三层去重。

    08 / 中文来源

    当前 DBLP 语料覆盖 453 条会议记录，但原生中文会议元数据为 0；这反映 DBLP 偏重英文国际出版物的收录范围，而非中文成果不存在。
